# 测试与验收

## 1. 测试目标

验证题库完整性、资源引用、JavaScript 语法、响应式界面、练习流程、番茄钟、离线缓存和云同步安全边界。

## 2. 自动静态校验

运行：

```powershell
python tools\validate_project.py
```

检查项目：

- 发布资源是否齐全；
- `questions.js` 是否为合法 JSON 包装；
- 总数是否为 900；
- 判断 300、单选 300、多选 300；
- 题目 ID 是否唯一；
- 答案是否都能对应现有选项；
- 是否存在空题干或异常选项数；
- HTML 资源版本和 Service Worker 版本是否一致；
- 是否误包含 Secret/Service Role；
- Node 可用时执行 `node --check`。

## 3. UI 冒烟测试

运行：

```powershell
python tests\smoke_ui.py
```

覆盖：

- 首页显示 900；
- 登录弹窗可打开；
- 随机练习设置弹窗可打开；
- 只选判断题并设置 10 题后，首题类型为判断，进度为 `1 / 10`；
- 番茄钟设置 1 分钟后悬浮窗显示 `01:00`；
- 捕获页面 JavaScript 错误。

## 5. 手工跨设备验收

发布后按以下步骤：

1. 电脑登录账号，收藏一道题并答错一道题。
2. 等待“学习记录已同步”。
3. 手机使用同一邮箱登录。
4. 刷新后确认收藏和错题出现。
5. 手机断网答题，确认页面仍能使用。
6. 恢复网络/VPN，点击立即同步。
7. 电脑刷新，确认手机新增记录出现。
