# 产品与需求

## 1. 项目背景

用户准备参加“人工智能训练师三级/高级工”认定，需要一个比 Word、PDF 和纯文本题库更适合碎片时间使用的学习工具。核心场景包括电脑复习、iPad 长时间练习、手机地铁刷题和多设备进度衔接。

## 2. 产品定位

本项目是一款个人考试题库 PWA：

- 浏览器打开即用，不要求安装 EXE。
- 一套界面适配电脑、平板和手机。
- 可以添加到主屏幕，外观和使用方式接近 App。
- 离线优先，网络恢复后云同步。

它不是微信小程序，也不是原生 iOS/Android 应用。

## 3. 目标用户

- 主要用户：人工智能训练师三级考生。
- 使用能力假设：能够使用浏览器和邮箱，不要求编程知识。
- 设备：Windows 电脑、iPad、iPhone 或安卓手机。

## 4. 核心需求

| 需求 | 解决方式 | 验收标准 |
| --- | --- | --- |
| 随时刷题 | HTTPS 网站 + PWA | 手机、电脑均可打开 |
| 地铁使用 | Service Worker 缓存 | 已加载后断网仍能进入题库 |
| 题型选择 | 判断/单选/多选筛选 | 可单选或任意组合 |
| 记住错题 | 本地状态和云端 JSON | 答错后进入错题本 |
| 重复错题 | 错误次数累计 | 错题页显示“错 N 次” |
| 巩固规则 | 连续答对两次 | 满足后移出待巩固列表 |
| 多设备 | Supabase 邮箱登录 | 同一账号可拉取进度 |
| 专注学习 | 番茄钟 | 支持预设、自定义、暂停、提醒 |
| 模拟考试 | 限时随机组卷 | 交卷后显示分数和错题 |

## 5. 非目标

- 不提供付费课程、社区、排行或广告。
- 不自动判定官方报名资格。
- 不承诺题库答案全部经过官方复核。
- 不替代正式考试系统。
- 当前不提供教师后台或多人题库编辑器。

## 6. 成功指标

- 题库完整加载 900 题。
- 核心练习流程无阻塞。
- 手机宽度下无横向页面溢出。
- 离线重新打开后能继续练习。
- 登录用户能在两台设备看到相同收藏和错题。
- 更新部署后不再长期停留在旧缓存版本。
