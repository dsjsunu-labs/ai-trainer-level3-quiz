# 用户使用手册

## 1. 打开网站

在线地址：<<你的站点地址>>

若中国大陆网络打不开，可在有 VPN 时首次完整加载。首页显示“900 道三级理论题已准备好”说明题库加载成功。

## 2. 添加到手机主屏幕

### iPhone/iPad Safari

1. Safari 打开网站。
2. 点击分享。
3. 选择“添加到主屏幕”。

### 安卓

浏览器菜单选择“添加到主屏幕”或“安装应用”。

网站更新后若主屏幕仍显示旧版，删除旧图标，用浏览器打开带新版本号的网址刷新，再重新添加。

## 3. 登录同步

第一次设置：

1. 在 Safari 打开网页，通过邮件里的 `Sign in` 完成认证。
2. 返回网页，右上角显示绿色“已同步”。
3. 点击“已同步”，在“让主屏幕版直接登录”中设置并确认至少 8 位同步密码。

主屏幕版登录：

1. 打开主屏幕版，点击右上角“登录同步”。
2. 输入同一个邮箱和刚设置的同步密码。
3. 点击“直接登录并同步”。
4. 显示绿色“已同步”后，点击一次“立即同步”。

电脑、手机和 iPad 使用同一个邮箱和同步密码。同步密码是题库账号密码，不是 QQ 邮箱密码。

Supabase 免费邮件服务有频率限制。出现 `Email rate limit exceeded` 时不要连续重试，等待约一小时。同步密码设置完成后通常不需要再次发送邮件。

## 4. 选择题型

点击“顺序练习”或“随机练习”后：

- 勾选判断题、单选题、多选题；
- 至少选择一种；
- 可以任意组合；
- 随机练习可选 10/20/50/100 题。

## 5. 错题规则

- 答错自动进入错题本。
- 再次答错，错误次数继续增加。
- 连续答对两次后移出“待巩固”。
- 历史错误次数仍保留在统计中。

## 6. 番茄钟

1. 点击右上角番茄钟图标。
2. 选择 25/5、45/10、60/10 或输入自定义时间。
3. 点击开始专注。
4. 计时会在右下角悬浮。
5. 可点击悬浮窗暂停、继续或重置。

结束时网页会尝试响铃和振动。手机静音、浏览器限制或系统省电可能阻止声音。

## 7. 离线与同步

- 首次必须联网完整加载。
- 之后断网仍可刷题，本机记录不会立即丢失。
- 恢复 VPN/网络后再答一道题会触发自动同步。
- 最稳妥方式：点击“已同步”→“立即同步”→等待成功提示。
- 不要在未同步时清除浏览器数据。

## 8. 备份

进入“学习统计”：

- “导出进度”生成 JSON 文件；
- “导入进度”可恢复到另一设备。

即使使用云同步，也建议重要阶段定期导出一次。
