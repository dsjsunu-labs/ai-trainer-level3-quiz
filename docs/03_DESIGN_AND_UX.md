# 界面与交互设计

## 1. 设计目标

- 像成熟驾考/背词产品一样，打开后立刻知道下一步做什么。
- 长时间阅读不刺眼，使用低饱和米白背景和深绿色主色。
- 电脑充分利用横向空间，手机使用底部导航和大触控区域。
- 结果反馈明确，但避免过度动画干扰复习。

## 2. 视觉语言

| 变量 | 用途 |
| --- | --- |
| 米白 `--bg` | 页面背景，降低视觉疲劳 |
| 深绿 `--green` | 主品牌、正确状态、进度 |
| 荧光浅绿 `--lime` | 主要行动按钮 |
| 红色 `--red` | 错误状态和高频错题 |
| 琥珀色 `--amber` | 番茄钟、提醒 |

首页大标题使用宋体风格强调“学习工具”的编辑感，正文使用系统无衬线字体保证小屏可读性。

## 3. 信息架构

```text
首页
├─ 学习总览
├─ 顺序练习
├─ 随机练习
├─ 错题巩固
├─ 模拟考试
└─ 专项练习

全局功能
├─ 搜索
├─ 番茄钟
├─ 登录同步
├─ 收藏
└─ 学习统计
```

## 4. 核心交互

### 练习前题型选择

用户点击顺序或随机练习后，先勾选判断、单选、多选。随机练习还可选择 10/20/50/100 题。这避免把不想练的题型强制混入。

### 作答反馈

- 判断/单选：点击后立即判分。
- 多选：选择多个选项后点击“确认答案”。
- 正确项绿色，误选项红色。
- 显示正确答案和用户答案。

### 错题巩固

- 第一次答错后进入待巩固列表。
- 重复错误继续累计。
- 后续连续答对两次后移出待巩固列表。
- 历史错误总数不会清零。
- 没有错题时侧边栏不显示红色 `0`。

### 番茄钟

- 默认 25 分钟专注、5 分钟休息。
- 支持 45/10、60/10 和自定义。
- 开始后右下角悬浮显示。
- 基于绝对结束时间计算，页面切换或锁屏后不会因定时器暂停而延长。
- 完成时使用 Web Audio 和设备振动提醒。

## 5. 响应式策略

### 电脑

- 固定左侧导航。
- 首页主卡与学习进度并列。
- 专项模块三列展示。

### 手机/iPad 窄屏

- 隐藏侧边栏，使用底部五项导航。
- 首页卡片单列。
- 登录和番茄钟只显示图标，减少顶部拥挤。
- 弹窗宽度为屏幕减 30px。
- 番茄钟悬浮窗避开底部导航。

## 6. 可用性注意

- 主要按钮触控尺寸约 42–46px。
- 答题选项整行可点。
- 所有关键状态同时使用颜色和文字，不只依赖颜色。
- 搜索最多显示 100 条结果，避免小设备卡顿。
- 模拟考试退出和清空数据要求二次确认。
